# Mini RPG Window

## 概要

Java Swingを使用して作成した、ウィンドウ上で遊べるターン制のミニRPGです。  
プレイヤーは勇者を操作し、通常攻撃・防御・攻撃魔法・回復魔法を使って敵と戦います。

## 主な機能

- 勇者と敵のHP、勇者のMPを画面上に表示
- 攻撃力と防御力を使用した通常攻撃（最低1ダメージ）
- 次に受けるダメージを半分にする防御
- 消費MPを選択できる攻撃魔法
- 1MPを消費してHPを25回復する回復魔法
- 敵のランダム行動（通常攻撃・防御・攻撃魔法）
- 勝敗判定と再スタート
- 戦闘ログ内の名前・HP・MP・数字の色分け表示

## クラス構成

| クラス | 役割 |
| --- | --- |
| `GameMain` | ゲームを起動する |
| `GameWindow` | Swingの画面表示とボタン操作を管理する |
| `BattleManager` | ターン進行、ダメージ計算、勝敗判定を管理する |
| `GameCharacter` | 勇者と敵に共通する能力値と処理を管理する |
| `Hero` | 勇者固有の回復魔法を管理する |
| `Enemy` | 敵キャラクターを表す |

## 操作方法

- **攻撃**：通常攻撃を行います。
- **防御**：次に受けるダメージを半分にします。
- **回復魔法**：1MPを消費してHPを最大25回復します。
- **攻撃魔法**：消費するMPを選び、攻撃魔法を使います。
- **再スタート**：勇者と敵のHP・MPを初期状態に戻します。

## 実行方法

### Eclipse

1. プロジェクトをEclipseで開きます。
2. `src/minirpg/GameMain.java` を選択します。
3. 「Javaアプリケーションとして実行」を選択します。

### コマンドライン

プロジェクトのルートフォルダーで、次のコマンドを実行します。

```bash
javac -encoding UTF-8 -d out src/minirpg/*.java
java -cp out minirpg.GameMain
```
