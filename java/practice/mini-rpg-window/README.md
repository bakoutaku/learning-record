# Mini RPG Window

## 概要

Java Swingを使用して作成した、ウィンドウ上で遊べるターン制のミニRPGです。  
プレイヤーは勇者を操作し、通常攻撃・防御・攻撃魔法・回復魔法を使って敵と戦います。

## 主な機能

- 勇者と敵のHP、勇者のMPを画面上に表示
- 攻撃力と防御力を使用した通常攻撃（最低1ダメージ）
- 次に受けるダメージを半分にする防御
- 消費MPを選択できる攻撃魔法
- 1MPを消費してHPを25回復する回復魔法
- 敵のランダム行動（通常攻撃・防御・攻撃魔法）
- 勝敗判定と再スタート
- 戦闘ログ内の名前・HP・MP・数字の色分け表示

## クラス構成

| クラス | 役割 |
| --- | --- |
| `GameMain` | ゲームを起動する |
| `GameWindow` | Swingの画面表示とボタン操作を管理する |
| `BattleManager` | ターン進行、ダメージ計算、勝敗判定を管理する |
| `GameCharacter` | 勇者と敵に共通する能力値と処理を管理する |
| `Hero` | 勇者固有の回復魔法を管理する |
| `Enemy` | 敵キャラクターを表す |

## 操作方法

- **攻撃**：通常攻撃を行います。
- **防御**：次に受けるダメージを半分にします。
- **回復魔法**：1MPを消費してHPを最大25回復します。
- **攻撃魔法**：消費するMPを選び、攻撃魔法を使います。
- **再スタート**：勇者と敵のHP・MPを初期状態に戻します。

## 実行方法

### Eclipse

1. プロジェクトをEclipseで開きます。
2. `src/minirpg/GameMain.java` を選択します。
3. 「Javaアプリケーションとして実行」を選択します。

### コマンドライン

プロジェクトのルートフォルダーで、次のコマンドを実行します。

```bash
javac -encoding UTF-8 -d out src/minirpg/*.java
java -cp out minirpg.GameMain
```

## 自分で考えて実装した部分

ゲームの仕様と戦闘ロジックは、自分で考えて実装しました。

- `GameCharacter`：勇者と敵に共通するHP・MP・攻撃力・防御力と、ダメージ・防御・魔法・回復の基本処理
- `Hero`：勇者固有の回復魔法
- `Enemy`：敵キャラクターの定義
- `BattleManager`：ターン進行、通常攻撃と魔法攻撃のダメージ計算、敵のランダム行動、勝敗判定、再スタート
- HPが0未満にならない、回復後のHPが最大値を超えない、MP不足時は魔法を使えないなどの条件処理

クラスごとの役割を分け、画面部分を変更しても戦闘ロジックへの影響を小さくできる構成を意識しました。

## 生成AIの利用について

`GameWindow`を中心とするJava Swingの画面表示とボタン操作は、まだ授業で学んでいない内容だったため、生成AIの支援を受けて作成しました。

生成AIには、必要な画面構成、操作ボタン、表示したい情報、自分で作成した戦闘ロジックとの接続方法を伝え、実装の補助として利用しました。生成されたコードについては、実際に動作させて戦闘ロジックとの接続を確認し、分からないクラスやメソッドを調べながら内容を確認しています。

現時点では、ゲームの仕様と戦闘ロジックは自分で説明できます。Swingの画面部品、レイアウト、イベント処理については学習中であり、今後は生成AIの支援なしでも同様の画面を作成できることを目標にしています。
