# learning-record

## 概要

HAL東京での授業課題や個人学習で作成したコードをまとめたリポジトリです。
Java、HTML/CSSを中心に、学習内容を整理しながら記録しています。

## 内容

このリポジトリでは、以下の学習内容を分類して管理しています。

```text
learning-record
├── java
│   ├── basic       # 基本文法・配列・集計処理
│   └── practice    # 入力処理・ゲーム・オブジェクト指向
└── html-css        # 基礎練習・Webページ制作
```

## Java

Javaの授業課題や練習プログラムをまとめています。

主な学習内容：

* 条件分岐・繰り返し処理・配列
* 入力値のチェックと集計処理
* クラス・インスタンス・コンストラクタ
* カプセル化・継承
* 乱数を使ったゲーム処理
* 機能ごとに役割を分けたクラス設計

代表的な成果物：

| 成果物 | 内容 |
| --- | --- |
| [Mini RPG Window](java/practice/mini-rpg-window/) | 攻撃・防御・魔法・勝敗判定を実装したターン制RPG |
| [Doraemon Secret Item Game](java/practice/doraemon-secret-item-game/) | クラス、配列、乱数、重複チェックの練習 |
| [Doraemon & Pokemon Class Practice](java/practice/doraemon-pokemon-class-practice/) | クラス、インスタンス、コンストラクタ、配列の練習 |
| [Checkout Point Calculator](java/practice/checkout-point-calculator/) | 入力チェック、集計、途中終了、繰り返し実行の練習 |

## HTML / CSS

フロントエンド制作の授業課題や練習データをまとめています。

主な学習内容：

* HTMLの基本構造
* 見出し・段落・改行などの基本タグ
* 画像表示
* テーブル
* margin と padding
* Flexbox
* 2カラムレイアウト
* CSSによる装飾

## 生成AIの利用について

未学習の技術に挑戦する際、一部の成果物で生成AIを補助的に利用しています。

Mini RPGでは、ゲームの仕様、キャラクター管理、戦闘ロジックを自分で考えて実装し、まだ授業で学んでいないJava Swingによる画面表示とボタン操作の部分で生成AIの支援を受けました。生成されたコードは、実際の動作と自分の戦闘ロジックとの接続を確認し、分からない部分を調べながら学習に利用しています。

詳しい利用範囲は、[Mini RPGのREADME](java/practice/mini-rpg-window/README.md#生成aiの利用について)に記載しています。

## 目的

授業で学んだ内容を復習し、基礎的なプログラミング力とWeb制作スキルを身につけることを目的としています。
また、学習記録を整理することで、自分の成長や理解度を確認できるようにしています。
