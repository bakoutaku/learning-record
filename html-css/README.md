# HTML / CSS

## 概要

HAL東京の「WF15 フロントエンド制作」の授業で作成した、HTML / CSSの学習記録です。  
HTMLでWebページの構造を作成し、CSSで見た目やレイアウトを調整する練習を行っています。

基礎練習から、1ページ構成のWebページ制作、複数ページ構成のカフェサイト制作までをまとめています。

## 内容

このリポジトリでは、HTML / CSSの基礎練習とページ制作課題を管理しています。

```text
html-css/
├── WF15_05_カフェサイト/
├── wf15-03-html-css/
├── wf15-04-dining-table/
└── README.md
```

## 課題一覧

| フォルダ | 内容 |
|---|---|
| `wf15-03-html-css` | HTML / CSSの基礎練習 |
| `wf15-04-dining-table` | 「ある日の食卓」をテーマにした1ページ構成のWebページ制作 |
| `WF15_05_カフェサイト` | 架空カフェ「café5963」をテーマにした複数ページ構成のWebサイト制作 |

## wf15-03-html-css

HTML / CSSの基本的なタグやレイアウトを学習するための練習データです。

主な学習内容：

- 見出しタグ
- 段落タグ
- 改行タグ
- マークアップ
- `div` と `span`
- 画像表示
- テキスト回り込み
- テーブル
- `margin` と `padding`
- Flexbox

## wf15-04-dining-table

「ある日の食卓」をテーマにした1ページ構成のWebページです。  
画像、文章、リスト、2カラムレイアウトを使い、HTML / CSSによるページ制作を練習しました。

主な学習内容：

- 画像と文章の配置
- `main` と `aside` を使った構成
- Flexboxによる2カラムレイアウト
- 背景画像の設定
- 見出しデザイン
- 余白の調整

## WF15_05_カフェサイト

架空カフェ「café5963」をテーマにした、複数ページ構成のWebサイトです。  
トップページ、メニューページ、アクセスページ、お問い合わせページを作成しました。

### ページ構成

| ファイル名 | 内容 |
|---|---|
| `index.html` | トップページ。カフェの紹介、コーヒー・パンの説明、NEWSを掲載 |
| `menu.html` | メニューページ。前菜、魚料理、肉料理、デザートを掲載 |
| `access.html` | アクセスページ。Googleマップ、住所、電話番号、メールアドレスを掲載 |
| `contact.html` | お問い合わせページ。名前、メールアドレス、メッセージ入力フォームを設置 |
| `css/style.css` | サイト全体のデザイン、ナビゲーション、各ページのレイアウトを設定 |

### 主な学習内容

- 複数ページ構成のWebサイト制作
- 共通ヘッダー・共通フッターの作成
- ナビゲーションリンクによるページ移動
- Flexboxを使った横並びレイアウト
- `nth-child` を使った要素の並び替え
- Googleマップの埋め込み
- テーブルによる店舗情報の整理
- お問い合わせフォームの作成
- 外部CSSファイルの読み込み
- 画像ファイルのパス指定

### フォルダ構成
